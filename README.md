# GPU price history

Every published Computable GPU Index print, one CSV per GPU per month
(`history/<SKU>/YYYY-MM.csv`), appended by `.github/workflows/poll.yml` on `main`.

Index values: Computable GPU Index (CGI), (c) 2026 Computable,
https://github.com/getcomputable/gpu-index, licensed CC BY-NC 4.0.
Stored as published, not recomputed. Times are UTC.
